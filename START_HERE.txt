========================================
  ZRG Oblivion Bot — КАК ЗАПУСТИТЬ 24/7
========================================

Бот готов к запуску. Основной файл: bot.py
Зависимости: только стандартная библиотека Python.

========================================
  1) ПЕРВЫЙ ЗАПУСК НА ПК
========================================

1) Установи Python 3.11+ с python.org
   При установке включи галочку:
   [x] Add Python to PATH

2) Открой папку pubg_clan_bot

3) Создай файл .env рядом с bot.py
   Можно скопировать .env.example -> .env

4) Впиши:

   BOT_TOKEN=твой_токен_от_BotFather
   ADMIN_IDS=твой_Telegram_ID

   Если админов несколько:
   ADMIN_IDS=123456789,987654321

5) Запуск:

   python bot.py

   Или авто-рестарт:

   python run_forever.py

   На Windows можно открыть:
   start_windows.bat

========================================
  2) КАК УЗНАТЬ ADMIN_IDS
========================================

Если не знаешь свой Telegram ID:
1) временно запусти бота только с BOT_TOKEN
2) напиши боту /id
3) скопируй число в .env:

   ADMIN_IDS=123456789

4) перезапусти бота

Без ADMIN_IDS админ-панель будет закрыта.

========================================
  6) ЗАЩИТА ОТ CONFLICT GETUPDATES
========================================

Проблема пофикшена на уровне кода:

1) Если случайно запустить две копии на одном ПК/VPS,
   вторая копия не стартует из-за lock-файла data/bot.lock.

2) Если где-то уже работает удалённая копия с этим же BOT_TOKEN,
   новая копия уйдёт в passive standby и перестанет опрашивать Telegram.
   Это убирает бесконечную ошибку:
   Conflict: terminated by other getUpdates request

3) Чтобы активировать нужную копию:
   - останови старую копию на ПК/хостинге
   - перезапусти нужную копию

Опционально:
CONFLICT_MODE=exit
Тогда при конфликте бот завершится с кодом 75 вместо standby.
