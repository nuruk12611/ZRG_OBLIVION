========================================
  ZRG OBLIVION BOT — УСТАНОВКА НА ПК
========================================

1) Python
   - Скачай: https://www.python.org/downloads/
   - При установке ОБЯЗАТЕЛЬНО галочка:
     [x] Add python.exe to PATH
   - Установи

2) Папка бота
   - Распакуй архив zrg_bot_pc.zip
   - Или скопируй папку pubg_clan_bot на ПК
   - Путь лучше без кириллицы, например:
     C:\bots\pubg_clan_bot\

3) Токен
   - Файл .env должен быть рядом с bot.py:
     BOT_TOKEN=123456:ABC...
     ADMIN_IDS=твой_Telegram_ID
   - Если нет — скопируй .env.example в .env

4) Запуск (самый простой)
   - Дважды кликни: start_windows.bat
   - Окно ЧЁРНОЕ не закрывай
   - В Telegram: /start боту

5) Если bat не работает
   Открой cmd в папке бота и:

     python -m pip install -r requirements.txt
     python bot.py

   Или с авто-рестартом:

     python run_forever.py

6) Защита от Conflict getUpdates
   - Если случайно открыть бота два раза на этом ПК,
     вторая копия не стартует из-за data/bot.lock
   - Если бот уже работает на другом хостинге,
     эта копия уйдёт в standby и не будет спамить ошибками
   - Чтобы сделать активной именно эту копию:
     останови старую копию и перезапусти эту
   - Для 24/7 потом перенесёшь эту же папку на хост

7) Проверка что живой
   В окне должно быть примерно:
     ONLINE @ZRG_Oblivion_bot
     POLL READY
   И бот отвечает на /start

8) Остановка
   В окне: Ctrl+C
   или просто закрыть окно

========================================
  ЧТО ДАЛЬШЕ
========================================
Когда на ПК всё ок — скажи:
  "на пк работает, делаем второго бота"
и/или
  "переносим на хост ..."
