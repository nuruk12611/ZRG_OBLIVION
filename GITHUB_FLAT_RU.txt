========================================
  GITHUB БЕЗ ПАПОК — КАК ЗАЛИТЬ БОТА
========================================

Если GitHub/телефон не даёт загрузить папки assets/ и data/,
это больше не проблема.

Бот сам создаёт на хостинге:
- assets/
- data/

И сам создаёт JSON-базы внутри data/:
- users.json
- states.json
- counters.json
- applications.json
- tickets.json
- appeals.json

========================================
  ЧТО ЗАГРУЗИТЬ В КОРЕНЬ РЕПОЗИТОРИЯ
========================================

Обязательно:
- bot.py
- requirements.txt

Для деплоя по платформам:
- amvera.yaml       если Amvera
- render.yaml       если Render
- Procfile          если Render/Heroku-like
- koyeb.yaml        если Koyeb, не обязательно

Баннеры просто в корень рядом с bot.py:
- about.jpg
- admin.jpg
- apply.jpg
- menu.jpg
- support.jpg
- unmute.jpg

Можно также загрузить:
- README.md
- START_HERE.txt
- AMVERA_RU.md
- RENDER_RU.md
- KOYEB_RU.md

НЕ загружать:
- .env
- bot.log
- data/*.json

========================================
  НА ХОСТИНГЕ
========================================

Переменные окружения:
BOT_TOKEN=токен_бота
ADMIN_IDS=твой_Telegram_ID
CLAN_NAME=ZRG OBLIVION

Команда запуска:
python bot.py

При старте бот найдёт JPG рядом с bot.py,
создаст assets/ и data/, затем начнёт работу.
